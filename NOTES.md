# Примечания к решению

Исходная сборка — Create React App на React 18: `react-scripts`, точка входа `src/index.js` через `ReactDOM.render` и пустой экран «hello there». Данные уже лежали в `src/services/api.js`, картинки — в `public/images`. Структуру этих данных мы не перестраивали: размеры по-прежнему id внутри цвета, справочник размеров — отдельно.

## Сборка

Create React App больше не поддерживается, поэтому проект переведён на Vite 8. Так сейчас рекомендует и документация Vite, и React: приложение монтируется через `createRoot` и `StrictMode`, `index.html` лежит в корне и подключает `src/main.tsx` как ES-модуль.

Команды другие: разработка — `npm run dev`, проверка типов и сборка — `npm run build` (`tsc -b`, затем Vite).

## Каталог

Сделаны три страницы из задания: список, карточка и корзина.

- Список ищет по названию, оставляет только товары в наличии и сортирует по минимальной цене среди цветов.
- На карточке своя галерея, без стороннего слайдера. Недоступные для выбранного цвета размеры заблокированы. В корзину добавляется одна штука. Если id нет, показывается «Товар не найден».
- Корзина уникальна по связке товар + цвет + размер. Количество можно менять и позицию удалять. Кнопка корзины есть на каждой странице и показывает число штук и сумму.

Дополнительно, как плюс из задания:

- выбранные `color` и `size` пишутся в query-параметры и восстанавливаются по ссылке;
- в корзине есть промокоды `SALE10` (10%) и `MINUS50` (минус 50).

## Состояние

TanStack Query и Zustand разделены по роли, как это описано в документации TanStack Query.

Query — кэш серверных данных. Им загружаются товары, размеры, категории и карточка: отсюда состояния загрузки, ошибки и повторный запрос. Для корзины он не подходит: это не ответ сервера, а выбор пользователя.

Корзина лежит в Zustand. Задание требует восстановить её после перезагрузки, поэтому стор пишет в `localStorage` (ключ `itcase-cart`) через `persist`. Старый формат этой записи тоже читается. Менеджер заменяет память на время сессии, а не сам `localStorage`.

## TypeScript

Проект переведён на TypeScript 7 по схеме Vite: отдельные `tsconfig.json`, `tsconfig.app.json` и `tsconfig.node.json`, `jsx: react-jsx`, строгий режим и типы `vite/client`. Типы описаны для товаров, корзины и промокодов. Сборка не проходит, если типы сломаны.

Исходники — `.ts` и `.tsx`. Рядом с ними не должны появляться скомпилированные `.js`: их выпускает только случайный `tsc` без `noEmit`, в репозиторий они не входят.

## Мелочи интерфейса

- Фильтр «В наличии» не переносится и стоит в одном ряду с поиском и сортировкой.
- Ко всем ценам добавлен ₽.
- На время ввода поиска или смены сортировки список ненадолго становится чуть прозрачнее.
- Сообщение об успешном промокоде стоит под полем, а не в одной строке с кнопками.
